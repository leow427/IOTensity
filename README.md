# IOTensity

A desktop app for arranging room lights, previewing screen colors, and controlling ESP32 RGB LEDs over local Wi-Fi. Built with React, TypeScript, Tauri, Rust and React Three Fiber.

- [Development setup, architecture and engineering conventions](AGENTS.md)
- [ESP32 wiring, flashing, Wi-Fi provisioning and emulator testing](docs/esp32-setup.md)

Arrange lights in **Your Rooms**, save, then choose a source and **Start Sync**. Virtual and physical lights have separate add buttons and lists. The native app supports persistence and sync; browser preview is a temporary room editor. Display capture requires macOS and Screen Recording permission.
